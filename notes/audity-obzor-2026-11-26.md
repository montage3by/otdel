## Итог
Аналитический уровень высокий — выше типичных агентских аудитов. Главное достоинство: результат считается по воронке вниз (форма → CRM → оплата), факты отделены от гипотез, есть блоки «что не делать». Главные слабости — формат и применение:
- аудиты написаны для специалиста, но местами выглядят как документ для клиента;
- много оговорок и англицизмов;
- в нескольких — служебные данные: логины кабинетов, ссылка на таблицу валидации;
- нет учёта, что внедрено по рекомендациям;
- нет ни одного аудита VK Ads.

## Сильные стороны (с примерами)
1. **CPL обманывает — доказано на данных:**
   - Пекарня: «Города 100+» — форма ~1 733 ₽, CRM-событие ~279 тыс. ₽; Поиск по CRM в ~3,7 раза эффективнее РСЯ;

3. **Декомпозиция CPA = CPC / CR.** Пекарня, спад 27.07–02.08: 84% потерь — падение CR, 16% — трафик. Образцовое расследование.
4. **Блоки «что не делать»** защищают работающее: Кинза — товарку не трогать, МВЕУ — аккаунт не ломать.
5. **Конкретные проверяемые находки:**
   - АСПЭК: попап на ПК, нерабочая кнопка К5.3, дата «31.09»;
   - Кама: цель шахматки на узком URL;

## Что поправить (по приоритету)
1. **Внутренняя и клиентская версии.** Большинство написаны «для коллеги» и открыто показывают ошибки ведения (Формула, Кама, Ларива, АСПЭК). Подписи «внешний», «независимый аудит» на собственных проектах агентства в руках клиента работают против нас. Для клиента нужна отдельная версия на 2–3 страницы: что видим, что делаем, что нужно от клиента.
2. **Служебные данные.** Убрать перед любой внешней отправкой:
   - логины кабинетов (e-…, porg-…);
   - ссылку на таблицу «Валидация_Настоящая пекарня» в аудите Пекарни за сентябрь–октябрь — в таблице телефоны;
   - ID счётчиков.
3. **Бренд.** Клиентские версии — под «Отделом»; Pluha — внутренняя методика. Уточнить у Игоря, что такое Pluha Analytics (его инструмент?) и как обрабатываются данные кабинетов клиентов.
4. **Язык.** Убрать или перевести англицизмы и жаргон: downstream, submit, performance, executive summary, PASS WITH LIMITATIONS, LOW COVERAGE, MAX AUDIT. Опечатка в МВЕУ: «небредовый» / «небред» (нужно «небрендовый»).
5. **Оговорки.** Сейчас почти в каждом блоке — «это не доказательство…». Для специалиста это ценно, для руководителя и клиента размывает решение. Оставить один блок «Границы данных» в конце.
6. **Технические артефакты:**
   - Ракета Max — ID объявлений в научной нотации (1.92…E+18);
   - МВЕУ — сломанные цифры на первой странице («2 1 669 457»);
   - Удача 23.11 — разрядка заголовков ломает текстовый слой PDF;
   - Ракета Max — 17 разделов, тяжело читать.
7. **Учёт внедрения.** Нужен трекер «рекомендация → кто → внедрено → эффект через 2–4 недели». Готовая основа — шаблон «3 месяца до / 3 после» из аудита Аромы.
8. **Покрытие:**
   - нет аудитов VK Ads, а это ~22% открутки и ~10 проектов Никиты;
   - UX-аудиты только по десктопу, хотя у Формулы 93% рекламных визитов — смартфоны.

## Как использовать
- **Кейсы для квартальной презентации и продаж:**
  - Кинза — ДРР 9,54% → 3,79%, покупки 63 → 204 в месяц (июнь → сентябрь);
  - Арома — CR ×2,45, CPA чайной МК на Поиске ~3 000 → ~1 488 ₽;
  - Пекарня — Поиск против РСЯ по CRM.
- **Ретро Ракеты (задача с 24.11):** Max 16.10 + v4 13.11 + UX 12.10 уже дают ~80% ретро. Цепочка: бренд → «Франшиза шаурма» после остановки по балансу, CRM-цели, модель против кейсов франчайзи.
- **Клиентские разговоры:**
  - МВЕУ — аудит ещё в сентябре предупреждал: «CRM-оплаты после августа подозрительно редкие». Это аргумент к теме повторных статусов;
  - Удача 23.11 — хронология внешних ограничений: нет доступа к Яндексу неделю в октябре, ожидание бюджета, авария Beget. Готовый материал для задачи «до/после изменений клиента»;
  - Формула — связка «креатив → лендинг» к разговору о риске ухода;
  - Ижсинтез v06 — обоснование свернуть B2B в Директе и тест Ozon 30–40 тыс. ₽.
- **Аудит как продукт агентства** (встреча по воронке продаж 26.11, «решение конкретной проблемы»):
  - экспресс-формат 2–4 страницы (Кама, Ракета v4) — для пресейла;
  - Max — платный продукт;
  - UX/CRO — к КП на сайты (Лувр Спорта).

  Шаблон для текущих запросов: аудит застройщика (Марина → Игорь), аудит франшизы «Дом хлеба».
- **Light Audit WEEK** (формат «Цифры / Что произошло / Почему / Что делаем / Что контролируем») — стандарт недельного комментария в дневниках. Закрывает правило 24.11 «фиксировать причины невыполнения KPI».
