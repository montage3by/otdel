# SEO-аудит сайта izhsintez.ru — 18.11.2026

**Что проверено.**
- Обошли все 262 адреса сайта: 3 карты сайта, ссылки из меню и служебные URL. Ответили кодом 200 — 252, кодом 404 — 10.
  - 153 карточки товаров;
  - 53 статьи «Школы ремонта»;
  - 19 категорий;
  - 7 страниц брендов и магазина;
  - около 15 служебных и информационных страниц.
- Для каждой страницы проверили title, description, H1, canonical, robots, микроразметку, объём текста, alt у картинок, ссылки, время ответа и вес HTML.
- Скорость мерили в браузере Chromium в двух режимах: мобильная эмуляция (медленная сеть, замедленный процессор) и десктоп. Замеры шли из облака, поэтому цифры ориентировочные. API PageSpeed Insights был недоступен: исчерпана дневная квота.
- Для сравнения посмотрели сайты конкурентов и выдачу.

**Чего нет и что нужно для второго этапа:**
- доступ к Яндекс Вебмастеру и Метрике клиента: реальная индексация, позиции, запросы, трафик;
- частотность из Wordstat или Keys.so.

Частотность и сложность в разделе 4 — экспертная оценка, не данные сервисов.

Постраничная таблица со всеми найденными проблемами: `exports/Ижсинтез_SEO_постраничный_аудит.csv`.

## 1. Итог в пяти предложениях

1. **База хорошая.**
   - Каталог из 153 товаров, 19 категорий, 53 статьи.
   - Чистые ЧПУ, HTTPS, корректные 301 на основное зеркало, Rank Math.
   - Карта сайта, микроразметка Product, BlogPosting и BreadcrumbList.
   - Для производителя такой объём контента — сильная сторона.
2. **Мешают шаблонные ошибки, которые бьют по всему сайту сразу:**
   - ни на одной карточке товара нет H1;
   - на категориях по 3–13 H1;
   - у главной description «Качественная мебель для дома, дачи, офиса»;
   - в главном меню 8 битых ссылок на каждой из 262 страниц;
   - категории не попадают в карту сайта.
3. **Сайт тяжёлый и медленный.**
   - HTML главной весит 3,4 МБ, из них 2,7 МБ — встроенный SVG.
   - На каждой странице ~50 CSS и ~55 JS-файлов, шрифт-иконки на 594 КБ, reCAPTCHA грузится трижды.
   - Категория на мобильном — LCP около 30 секунд.
4. **Нет связки с продажами и аналитикой.**
   - Счётчик Яндекс Метрики на сайте не загружается.
   - В карточках нет ссылок на маркетплейсы (Ozon) и цен. В разметке цена «0.00 ₽» — в сниппете это выглядит как бесплатный товар.
5. **Оценка: «нужна работа», но не «критично».**
   - Три приоритета: шаблоны H1, title и description; карта сайта и битые ссылки; скорость.
   - Технически почти всё правится на уровне шаблонов WordPress, Elementor и Rank Math за 2–3 рабочих дня разработчика.

**Реалистичная стратегия.**
- По общим товарным запросам («грунтовка купить») выдачу Яндекса забирают маркетплейсы и сети: Ozon, Wildberries, Лемана Про, ВсеИнструменты, Петрович.
- Сайту производителя реально выигрывать:
  - брендовые запросы;
  - B2B-запросы (опт, дилерство, контрактное производство, «производитель»);
  - низкочастотные «тип + назначение + характеристика»;
  - информационные запросы со ссылкой на товар.

## 8. Что важно для нашей работы с Ижсинтезом (внутреннее, не для клиента)

1. **На сайте нет Яндекс Метрики.** Если Директ ведёт трафик на izhsintez.ru, оптимизация на конверсии работать не может. Проверить у Игоря, какой счётчик и какой домен стоит в кампаниях.
2. **SIP-мойки и химии для кофемашин, которые продвигаем в Директе, на izhsintez.ru нет.** Это направления «Ижсинтез-Химпром» — отдельный сайт. SEO-стратегию по B2B-направлениям завода нужно делать для того сайта; этот аудит — по ЛКМ («Ижсинтез-отделочные материалы»). Уточнить у Наташи, какой сайт клиент имел в виду, запрашивая SEO-консультацию.
3. **Ozon.** В карточках нет ссылок на маркетплейс. Это дешёвый способ добавить продажи с органики и дать Директу посадочную с понятным следующим шагом.
4. **Апсейл.** Пакет «SEO-техничка + тексты категорий + B2B-лендинги + Метрика» ложится в декабрьскую стратегическую встречу (комплексный пакет). Разработку на WordPress сами не делаем — нужен подрядчик клиента или наш внешний.
