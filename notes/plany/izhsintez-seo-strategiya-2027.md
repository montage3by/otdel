# Стратегия SEO-продвижения izhsintez.ru — декабрь 2026 – ноябрь 2027

**Основа:**
- SEO-аудит от 18.11.2026 — `notes/plany/izhsintez-seo-audit-2026-11-18.md`;
- контекст клиента со встреч ОПТ и планёрок ПМ.

**Сайт:** izhsintez.ru — «Ижсинтез-отделочные материалы», производитель ЛКМ и строительной химии. Ижевск, с 1996 года. Бренды SOLEX, OPTILUX, Коллекция, А3, Спутник, SHPATIS, Доброцвет, BAUTON, ZERWOOD.

**Поисковик:** приоритет — Яндекс, Google — вторым.

## 1. Цели и логика

**Бизнес-цели, которые закрывает SEO:**
1. **B2B-заявки:**
   - дилеры и дистрибьюторы;
   - строительные компании и прорабы;
   - торговые сети;
   - контрактное производство (private label).

   Это главный денежный поток с сайта производителя.
2. **Продажи через партнёров и Ozon.** Человек нашёл товар в поиске и ушёл покупать на маркетплейс или к дилеру из «Где купить».
3. **Брендовый спрос.** Человек, который ищет SOLEX, OPTILUX или «Коллекцию», должен попадать на сайт производителя, а не на случайный сайт.
4. **Снижение стоимости лида в Директе.** Те же страницы — посадочные для рекламы. Органика забирает часть спроса, который сейчас покупаем.

**Где сайт производителя реально может выигрывать в Яндексе:**

| Тип спроса | Пример | Шансы | Почему |
|---|---|---|---|
| B2B и производитель | «производитель ЛКМ», «грунтовка оптом от производителя», «контрактное производство красок» | **Высокие** | Маркетплейсы в этих запросах слабы, конкуренция — такие же заводы |
| Брендовый | «SOLEX краска», «OPTILUX противоморозная добавка» | **Высокие** | Наш бренд, нужны нормальные страницы брендов |
| Товар + назначение + характеристика (низкочастотный) | «эмаль для радиаторов без запаха», «огнебиозащита 2 группы», «краска для печей» | **Средние–высокие** | Мало сильных страниц, нужны тексты и характеристики |
| Информационный под товар | «как выбрать бетоноконтакт», «чем отличается С3 от комплексной добавки» | **Средние** | Есть база из 53 статей, нужна фокусировка |
| Общий товарный | «грунтовка купить», «краска для стен» | **Низкие** | ТОП занят Ozon, WB, Лемана Про, ВсеИнструменты. Сюда — только Директ и маркетплейсы |

**KPI** — целевые цифры ставим после месяца сбора данных в Метрике и Вебмастере (база сейчас неизвестна):

| Метрика | Как считаем | Ориентир на 12 месяцев |
|---|---|---|
| Индексация | Доля коммерческих страниц (категории, товары, B2B, бренды) в индексе Яндекса | 100% |
| Видимость по семантическому ядру | Доля ключей ядра в ТОП-10 Яндекса (Топвизор / Keys.so) | Рост от базы декабря; цель по B2B и брендам — 50%+ ключей в ТОП-10 |
| Органический трафик | Метрика, сегмент «Поисковые системы», без брендового | Рост от базы, контроль по месяцам с учётом сезона |
| B2B-заявки с органики | Цели Метрики на формы «Запросить прайс», «Задать вопрос», «Стать дилером», «Private label» | Считаем с первого месяца, цель — от базы |
| Переходы к продавцам | Клики «Купить на Ozon» и «Где купить» | Новая метрика: цель — от базы |
| Технические | LCP < 2,5 с, CLS < 0,1, 0 битых ссылок, 0 критичных ошибок в Вебмастере | К концу 1-го квартала |

## 2. Внутренняя оптимизация

### 2.1. Аналитика — делаем первой
- **Яндекс Метрика:**
  - сейчас на сайте не загружается;
  - настроить Вебвизор, цели: каждая форма, клик по телефону и почте, «Где купить», «Купить на Ozon», скачивание каталога PDF;
  - электронная коммерция не нужна — продаж на сайте нет.
- **Яндекс Вебмастер и Google Search Console:**
  - подтвердить права, загрузить карту сайта;
  - указать регион (Россия, с главным офисом в Ижевске);
  - включить мониторинг важных страниц.
- **Съём позиций** — Топвизор или аналог по ядру из 300–500 ключей, еженедельно.
- **UTM на все внешние ссылки на сайт:** маркетплейсы, сайты брендов, каталоги.

### 2.2. Семантическое ядро
- **Источники:** Wordstat, Keys.so или Букварикс, подсказки Яндекса, запросы из Вебмастера, поисковые фразы из Директа клиента, конкуренты.
- **Кластеры** (~300–500 запросов на старте):
  1. **B2B:** производитель, опт, дилерам, дистрибуция, private label, для строительных компаний, по ГОСТ.
  2. **Категории товаров:** грунтовки, бетоноконтакт, ВД-краски, эмали, шпаклевки, замазки и затирки, клеи, гидроизоляция, добавки для бетона, огнебиозащита, лаки, колерование, декор, удобрения и побелка, печи, средства для дома.
  3. **Назначение** — будущие посадочные из фильтров: краска для потолка, для ванной, фасадная, моющаяся, для детской, для радиаторов, для пола, для металла по ржавчине, для мебели, для печей.
  4. **Бренды:** SOLEX, OPTILUX, Коллекция, А3, Спутник, SHPATIS, Доброцвет, BAUTON, ZERWOOD.
  5. **Информационные:** как выбрать, чем отличается, расход, сколько сохнет, как наносить, сезонные.
  6. **Локальные:** «где купить в [городе]», «магазин Ижсинтез Ижевск», «фирменный магазин Хохряки».
- **Орфография и варианты:** бетоноконтакт / бетонконтакт / бетоконтакт, ВД / водоэмульсионная / водно-дисперсионная, Оптилюкс / OPTILUX.

### 2.3. Структура сайта

```
Главная (производитель ЛКМ)
├── Каталог
│   ├── Категории по типу (19, есть) → тексты, FAQ, ссылки на статьи
│   └── Посадочные по назначению (новые, 10–15): «Краски для потолка», «Фасадные краски»,
│       «Эмали для радиаторов», «Покрытия для пола», «По металлу и ржавчине», «Для мебели и декора», «Для печей»
├── Бренды (7–9 страниц-лендингов)
├── Для бизнеса (B2B-хаб)
│   ├── Производство и лаборатория
│   ├── Дистрибуция и дилерство
│   ├── Private label / контрактное производство
│   ├── Для строительных компаний и подрядчиков
│   └── Для торговых сетей
├── Где купить (по городам + маркетплейсы)
├── Школа ремонта (кластеры по категориям)
├── Документы (сертификаты, техлисты, каталог PDF)

```

- Одна схема URL категорий — `/category/...`. Все `/product-category/...` и `/jemali/` отдают 301 на правильные адреса.
- Хлебные крошки на всех уровнях (уже есть в разметке).
- **Брендовые поддомены и сайты** — решение клиента. Вариант А: перенести solex.izhsintez.ru на `/shop/solex/` с 301, на внешних сайтах брендов поставить ссылки на карточки. Вариант Б: оставить отдельно, но развести семантику (бренд-сайт — имидж, основной — каталог и B2B).

### 2.4. Техническая оптимизация (декабрь – февраль)

| Блок | Что делаем |
|---|---|
| Шаблоны | H1 на карточках товаров; убрать H1 из листинга; H1 на главной, брендах, B2B |
| Мета-теги | Шаблоны title и description в Rank Math для товаров, категорий, брендов, статей. Ручная правка топ-50 страниц. Убрать хвост « - ИЖСИНТЕЗ - группа компаний» |
| Индексация | Карта сайта категорий; убрать мусор из карт; `Clean-param` в robots.txt; снять noindex с «Печей»; склеить дубли товаров; исправить 8 битых ссылок меню |
| Скорость | Вынести 2,7 МБ SVG из HTML; объединить и отложить CSS/JS (~110 файлов); TTF-иконки 594 КБ → SVG или WOFF2; reCAPTCHA — один раз и по требованию; PNG → WebP, lazy-load; починить кэш (ответ сервера 2–8 с → < 0,8 с); шрифты локально. Цель: LCP < 2,5 с, CLS < 0,1 на мобильных |

### 2.5. Контент

**Категории (19) и посадочные по назначению (10–15) — главный рычаг.** На каждую:
- H1 с основным запросом;
- вводный абзац;
- блок «как выбрать»: таблица брендов и линеек, чем отличаются (эконом — Спутник и А3, оптимум — OPTILUX, премиум — SOLEX);
- расход и фасовки;
- FAQ (3–5 вопросов);
- ссылки на 2–3 статьи;
- «Где купить» и «Оптом — запросить прайс».

Объём 400–800 слов под листингом. Первая десятка — по сезону и марже (уточнить у клиента). Зимой: добавки для бетона, грунтовки, ВД-краски, шпаклевки, огнебиозащита. К весне: фасад, гидроизоляция, побелка, удобрения.

**Карточки товаров (153):**
- в title и H1 — бренд, тип, назначение, а для топ-товаров — фасовка;
- текст: назначение, преимущества, характеристики таблицей (расход, время высыхания, основа, фасовки, ГОСТ/ТУ), инструкция, FAQ;
- техлист и сертификат PDF;
- кнопки «Купить на Ozon» и «Где купить» с UTM, «Запросить оптовый прайс»;
- калькулятор расхода уже есть — плюс, развивать.

**Бренды (7–9 страниц):** позиционирование, линейки, топ-товары, где купить, отзывы и кейсы, 300–600 слов.

**B2B-хаб (4–5 страниц):** факты вместо общих слов — площадки и цеха, мощность, лаборатория, контроль качества, минимальные партии, сроки, логистика и регионы, маркетинговая поддержка дилеров, документы, кейсы. Форма с полями под квалификацию. Эти же страницы — посадочные для Директа и материалы для обзвона ЛПР (3-й сценарий клиента).

**«Школа ремонта»:**
- аудит 53 статей:
  - **усилить** статьи с коммерческим потенциалом (бетон зимой, грунтовки, мастики, ВД, мебель): обновить, добавить блок «Чем выполнить» с 2–4 товарами, FAQ;
  - **оставить как есть** нецелевые («скрытая спальня», «компенсация за ремонт»): не удалять, но и не развивать;
- новые статьи — 2–4 в месяц, только «товар + задача»: сравнения, «как выбрать», расход, сезон;
- контент-план по кластерам и сезонам — раздел 4.

**Экспертность:** у статей автор-технолог или лаборатория с короткой справкой, дата обновления, ссылки на ГОСТ. Это повышает доверие поиска и шанс попасть в ответы Нейро и Алисы.

### 2.6. Внутренняя перелинковка
- Категория ↔ статьи кластера (2–3 ссылки в обе стороны).
- Статья → 2–4 товара + категория (блок «Чем выполнить»).
- Карточка → сопутствующие товары. Блок «С этим товаром покупают» уже есть — наполнить по технологии: грунт → краска → колер.
- Бренд ↔ его категории и топ-товары.
- Главная → B2B-хаб, топ-категории, бренды.
- Анкоры — описательные, без «подробнее».

### 2.7. Коммерческие факторы Яндекса
Для сайта без цен и корзины это особенно важно.
- **Контакты и доверие:**
  - контакты на каждой странице, адрес завода и магазина, реквизиты;
  - фото производства и лаборатории, сертификаты, «С 1996 года».
- **Где и как купить:**
  - страница «Где купить» по городам;
  - ссылки на Ozon и других продавцов;
  - условия для опта и РРЦ (если клиент согласен), фасовки.
- **Удобство:**
  - формы и обратный звонок;
  - мессенджеры: Telegram, MAX, WhatsApp.

### 2.8. Поведенческие факторы — только честно
Скорость, понятная навигация, фильтры в каталоге, калькулятор, FAQ, видеоинструкции на карточках. Накрутку ПФ не используем: риск санкций Яндекса.

## 3. Внешняя оптимизация

### 3.1. Принципы
- Ссылочный профиль — естественный и тематический: строительство, ремонт, ЛКМ, Удмуртия.
- Не используем массовую закупку ссылок и прогоны: фильтр «Минусинск» в Яндексе.
- Брендовые упоминания (без ссылки) тоже работают на доверие и на ответы нейросетей.

### 3.2. Каналы

| Канал | Что делаем | Эффект | Регулярность |
|---|---|---|---|
| **Яндекс Бизнес / Карты, 2ГИС, Google Maps** | Карточки завода и фирменного магазина (д. Хохряки): фото, режим работы, товары, ссылка на сайт с UTM, сбор отзывов | Локальная выдача, доверие, брендовые запросы | Разово + отзывы постоянно |
| **Дилеры и магазины** | На сайтах дилеров — блок «Производитель: Ижсинтез» со ссылкой на карточку; дать им тексты и фото. Взаимно: на нашей странице «Где купить» — ссылки на дилеров | Самые естественные тематические ссылки | Через отдел продаж, 5–10 дилеров в квартал |

| **Видео** (RuTube, VK Видео, YouTube) | Инструкции по нанесению, сравнения, тесты в лаборатории; встроить в карточки | Видео-выдача, ПФ на карточках | 2–4 ролика в месяц |

### 3.3. GEO — ответы нейросетей (Нейро, Алиса, ChatGPT)
- Ясные факты на сайте: кто производитель, с какого года, бренды, где купить, характеристики — таблицами и FAQ.
- Единое написание брендов и компании на всех площадках.
- Упоминания в авторитетных источниках: СМИ, каталоги, отзывы.

- **Лето:** фасады, кровля, пол.
- **Осень:** подготовка к зиме.

Контент выкладываем за 1–2 месяца до пика, чтобы страницы успели проиндексироваться.

## 5. Ресурсы и роли

| Роль | Задачи | Загрузка |
|---|---|---|
| SEO-специалист | Семантика, ТЗ на тексты и правки, метатеги, перелинковка, внешние площадки, отчёты | Постоянно |
| Разработчик WordPress / Elementor | Шаблоны, скорость, разметка, страницы | Подрядчик клиента или наш внешний — сами WP не ведём. Пик 5–8 дней в декабре–феврале, дальше по задачам |
| Копирайтер с технической экспертизой | Категории, бренды, B2B, статьи | Начало — 15–20 текстов в месяц, дальше 4–8 |
| Технолог клиента | Проверка фактов, характеристики, экспертные цитаты, видео | 2–4 часа в месяц |
| Дизайнер | Баннеры, B2B-страницы, обложки | По задачам |
| Отдел продаж клиента | Дилеры, ссылки, отзывы, список «Где купить» | По задачам |

**Отчётность:** ежемесячно — позиции по кластерам, трафик и цели из Метрики, выполненные работы, план. Ежеквартально — пересмотр приоритетов вместе с Директом.

## 6. Связка SEO с Директом и другими каналами
- **Одни и те же посадочные.** Категории, B2B и бренды делаем так, чтобы они работали и для органики, и для рекламы. Метрика нужна обоим.
- **Обмен данными.** Запросы с конверсиями из Директа — в семантику SEO. Где SEO вышло в ТОП-3 — снижаем ставки в Директе.
- **Ozon.** Кнопки и ссылки с UTM показывают, сколько продаж приводит сайт. Вместе с выгрузкой Ozon от клиента это закрывает вопрос KPI по Ozon.
- **B2B-обзвон** (3-й сценарий, база ЛПР). Страницы «Для бизнеса» и каталог PDF — то, что отправляем после звонка.

## 7. Что нужно от клиента для старта
1. Доступы:
   - WordPress (или контакт разработчика);
   - Яндекс Метрика и Вебмастер (или разрешение создать);
   - хостинг для настройки кэша.
2. Решение по брендовым сайтам и поддомену SOLEX.
3. Приоритет категорий по марже и сезону; список дилеров и ссылки на Ozon.
4. Техлисты, сертификаты, фото производства и лаборатории, контакт технолога.
5. Факты для B2B-страниц: мощности, минимальные партии, сроки, регионы, условия.

## 8. Риски
- **Разработка на стороне клиента** может тормозить технические правки. Обязательно назначить ответственного разработчика и SLA.
- **Общие товарные запросы забирают маркетплейсы** — не обещаем ТОП по ним. Фокус на B2B, брендах и низкочастотных запросах.
- **Сезонность искажает помесячную динамику** — сравниваем год к году и по кластерам.
- **Брендовые сайты** могут конкурировать с основным в выдаче, пока не принято решение по консолидации.
