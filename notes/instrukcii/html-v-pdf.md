# HTML → PDF для презентаций (инструкции Рафиса, 17.11.2026)

Рафис прислал две инструкции: Edge на Windows и Playwright + Chromium. Здесь — суть.

## Как делаем в этом репозитории (облачная сессия Claude)
Playwright + Chromium уже установлены:
1. В HTML должно быть `@page{size:1600px 900px;margin:0}` и по одной `section` на слайд с `page-break-after:always`.
2. Открываем в Chromium с окном 1600×900, ждём загрузку, `page.pdf(width='1600px', height='900px', printBackground=True)`.
3. Проверяем результат: число страниц = числу слайдов, превью (скриншоты) — ничего не обрезано.

Пример: `exports/lada-forum-deck.html` → `exports/ЛАДА_ФОРУМ_предстратегия_Директ_VK.pdf`.

## На Windows без установки (вариант Рафиса)
Скрипт `html_to_pdf.ps1`: `msedge.exe --headless=new --disable-gpu --no-pdf-header-footer --virtual-time-budget=15000 --run-all-compositor-stages-before-draw --user-data-dir=<temp> --print-to-pdf=<out> file:///<in>`.

Ловушки:
- кириллица и пробелы в пути — Edge молча не создаёт PDF, нужно копировать во временную папку;
- запускать с ожиданием процесса (`Start-Process -Wait`);
- без `@page` получится A4;
- без `print-color-adjust:exact` не напечатаются фоны;
- картинки во внешней папке нужно класть рядом с HTML.

## Формат КП агентства (по образцам Рафиса и Антона)
Светло-голубой фон, белые и тёмно-синие карточки с оранжевой полосой сверху, надзаголовок «NN · ТЕМА» оранжевым, логотип «Отдела» слева, логотип клиента справа. 16:9, 1600×900.

Образцы:
- «Avdeeva_Direct» — 19 слайдов, Директ 60 тыс. ₽/мес, лендинг 30–50 тыс. ₽;
- «XMachinery_KP_Otdel» — 17 слайдов, Директ 80 тыс. ₽/мес, лендинг 50 тыс. ₽ за страницу.
